# SnapmakerOrca-FullSpectrum Plus v0.9.19

Based on v0.9.18 (unchanged and still available as release v0.9.18).

## New
- Cut tool > Connectors: new **Ball** joint type (ball on one part, snap-in spherical socket on the other). Size = ball diameter; depth is automatic; tolerance = clearance.
- Cut tool > Connectors: new **Microchip** type: blind cylindrical cavity only (no part added). Size = chip diameter, Depth = chip length, tolerance = clearance. Click on the cut face to place it; Flip changes the side.

## Side by side with v0.9.18
- Own settings folder (`%APPDATA%\Snapmaker_Orca_Plus`), own install folder, own uninstall entry and desktop shortcut.

## Coming next
- Hinge and Dovetail joints, clearance profiles per printer/material, calibration piece.
